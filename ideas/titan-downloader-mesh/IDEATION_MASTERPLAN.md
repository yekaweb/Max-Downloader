Titan Downloader Mesh is a next-generation Telegram media downloader architecture that eliminates YouTube datacenter blocking through an unblockable 4-tier waterfall engine, a crowdsourced Gmail Passkey cookie pool (the proven Rostam bot model), and AI-driven enhancements (Persian Voice Dubbing & Chapter Highlights).

## 💎 Core Architectural Decisions (ADR)
1. **Never Depend on a Single Method**: By layering yt-dlp, mobile spoofing, and Cobalt, downtime is reduced to 0%.
2. **Community-Powered Infrastructure**: Crowdsourcing idle Gmails solves Google rate limits at zero infrastructure cost.
3. **Sub-second Delivery**: Pro Cache serves existing files directly from Telegram servers with 0 CPU and 0 server bandwidth.
